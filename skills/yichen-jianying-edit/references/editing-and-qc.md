# 基础草稿质检

本页只覆盖当前开放的 H.264 视频与普通字幕，不提供转写、音频渲染、自动语义删减、
独立音效或导出脚本的执行指引。超出范围的任务交给宿主决定。

核对字幕与用户提供的原文，保护数字、产品名和关键判断；字幕不要遮挡重要画面。
有裁切时确认原片区间和目标时长相等、前后语义完整，避免剪掉发音。

构建后执行结构验证。若本次获准登记与原生验收，检查画面、字幕和源片声音，
保存、退出、冷重开后再做只读回读。结构一致不能代替实际播放或人工听感。
报告明确区分已执行检查、未检查项目及未解决问题；只在新改动或发现问题时追加验证。
操作命令见 [基础流程](headless-macos.md)。
